# План улучшения сайта-резюме

## Цель

Сделать сайт-резюме не просто красивой визиткой, а демонстрацией инженерного мышления: работа с данными, API, AI, UX, проектная логика и понятная польза для HR/работодателя.

## Приоритеты

### 1. Project Deep Dive

**Зачем:** обычные карточки проектов показывают только факт наличия репозиториев. Кейс-формат показывает, как я думаю и решаю задачи.

**Что добавить:**
- [ ] Для каждого важного проекта сделать расширенную карточку.
- [ ] Добавить структуру: проблема, решение, стек, сложность, результат, чему научился.
- [ ] Добавить фильтр по направлениям: SQL, 1C, React, Backend, AI, учебные проекты.
- [ ] Выделить 3-5 главных проектов вместо равномерного показа всех репозиториев.

**Минимальная реализация:**
- [ ] Расширить данные проектов в `githubService.js` или вынести в отдельный `projectsData.js`.
- [ ] Добавить кнопку "Подробнее".
- [ ] Сделать модальное окно или раскрывающуюся карточку.

## 2. Resume Match

**Зачем:** HR или работодатель вставляет вакансию, а сайт показывает, насколько мой опыт подходит под требования.

**Что добавить:**
- [ ] Поле для вставки текста вакансии.
- [ ] Анализ совпадающих навыков.
- [ ] Список недостающих навыков.
- [ ] Релевантные проекты под вакансию.
- [ ] Краткий вывод: "почему кандидат подходит".

**Минимальная реализация:**
- [ ] Сделать локальный анализ по ключевым словам без AI.
- [ ] Использовать навыки из `hhResume.json`.
- [ ] Сопоставлять текст вакансии с проектами и навыками.

**Расширенная реализация:**
- [ ] Подключить существующий AI endpoint `/api/ai`.
- [ ] Добавить отдельный prompt для анализа вакансии.
- [ ] Ограничить ответ только данными сайта и резюме.

## 3. AI-рекрутер по сайту

**Зачем:** текущий AI-ассистент скорее декоративный. Его можно превратить в полезный инструмент для HR.

**Что добавить:**
- [ ] Быстрые кнопки: "Подходит ли под вакансию?", "Суммируй опыт", "Покажи проекты с SQL", "Составь письмо работодателю".
- [ ] Передавать ассистенту контекст резюме и проектов.
- [ ] Сделать ответы короткими и полезными.
- [ ] Добавить отказ от выдумывания фактов.

**Минимальная реализация:**
- [ ] Переделать `AIAssistant` из информационного попапа в небольшой чат.
- [ ] Добавить preset-вопросы.
- [ ] Использовать `askOpenRouter`.

## 4. Терминал-резюме

**Зачем:** запоминающаяся фича для developer portfolio, которая показывает стиль и интерактивность.

**Команды:**
- [ ] `whoami` - короткое описание.
- [ ] `skills` - список навыков.
- [ ] `projects` - основные проекты.
- [ ] `projects --sql` - проекты, связанные с SQL.
- [ ] `contact` - контакты.
- [ ] `resume` - ссылка на PDF.
- [ ] `help` - список команд.

**Минимальная реализация:**
- [ ] Создать компонент `ResumeTerminal`.
- [ ] Добавить его после hero-блока или перед контактами.
- [ ] Хранить историю команд в состоянии React.

## 5. Живая GitHub-аналитика

**Зачем:** показывает работу с API и актуальную активность.

**Что добавить:**
- [ ] Количество публичных репозиториев.
- [ ] Последние обновленные проекты.
- [ ] Топ языков.
- [ ] Последний коммит или дата обновления.
- [ ] Суммарные stars.

**Минимальная реализация:**
- [ ] Расширить `githubService.js`.
- [ ] Добавить блок статистики над проектами.
- [ ] Закэшировать данные, чтобы не упираться в лимиты GitHub API.

## 6. Интерактивная карта навыков

**Зачем:** навыки становятся связанными с доказательствами, а не просто тегами.

**Что добавить:**
- [ ] Навыки как кликабельные узлы.
- [ ] При клике показывать связанные проекты.
- [ ] Разделить навыки на группы: frontend, backend, database, 1C, tools, AI.
- [ ] Подсветить основные направления: 1C + SQL.

**Минимальная реализация:**
- [ ] Сделать grid из skill-карточек.
- [ ] Добавить выбранный навык в state.
- [ ] Фильтровать проекты по выбранному навыку.

## 7. HR-режим

**Зачем:** отдельный быстрый сценарий для человека, который смотрит сайт 30-60 секунд.

**Что добавить:**
- [ ] Кнопка "HR-режим".
- [ ] Краткое резюме в 5 пунктов.
- [ ] Скачать PDF.
- [ ] Скопировать контакты.
- [ ] Показать 3 самых релевантных проекта.

**Минимальная реализация:**
- [ ] Добавить кнопку в navbar или hero.
- [ ] Сделать компактный блок/модальное окно.
- [ ] Подключить PDF из `src/data`.

## Рекомендуемый порядок реализации

1. [ ] Project Deep Dive.
2. [ ] HR-режим.
3. [ ] Resume Match.
4. [ ] Терминал-резюме.
5. [ ] GitHub-аналитика.
6. [ ] AI-рекрутер.
7. [ ] Интерактивная карта навыков.

## Критерии качества

- [ ] Фича помогает работодателю понять пользу, а не просто добавляет эффект.
- [ ] Фича работает на мобильных устройствах.
- [ ] Нет перегруза главной страницы.
- [ ] Есть fallback, если API или AI недоступны.
- [ ] Контактные данные защищены от случайного отображения там, где это не нужно.
- [ ] Тексты короткие и конкретные.

## Первая конкретная задача

Сделать `Project Deep Dive`:

- [ ] Создать данные для 3-5 ключевых проектов.
- [ ] Добавить раскрытие подробностей в карточке проекта.
- [ ] Показать стек, роль, проблему, решение и результат.
- [ ] Проверить адаптивность.
- [ ] Собрать проект через `npm run build`.
